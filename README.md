# Задание 1. Проектирование технологической архитектуры

Для обеспечения требуемой доступности и отказоустойчивости сервиса InureTech необходимо:

- распределяем входящий трафик между серверами или дата-центрами (выбираю подходящую геозону и ближайший сервер);
- провайдер cloudflaire (он то и дергает ручки health check серверов дабы направить запрос на активный и ближайший);
    * CDN (Content Delivery Network): Кэширует статический контент (изображения, CSS, видео) на 300+ серверах по всему миру. 
    * Защита от DDoS-атак: Одна из сильнейших на рынке
    * DNS-хостинг: Крупнейший в мире публичный DNS-провайдер (1.1.1.1). Молниеносное разрешение доменных имен
    * WAF (Web Application Firewall): Экранирует уязвимости веб-приложений (SQL-инъекции, XSS), блокирует ботов и вредоносные запросы
    * глобальная балансировка нагрузки (Global Load Balancer) — распределяет трафик между дата-центрами, автоматически отводя его от неработающих серверов
- использовать горизонтальное масштабирование и развернуть систему в нескольких зонах доступности;
- применить независимые кластеры Kubernetes в каждой зоне;
- реализовать глобальный и внутренние балансировщики нагрузки, включить механизмы health check;
- настроить кластер PostgreSQL с репликацией и регулярным резервным копированием;
- предусмотреть автоматическое переключение трафика между зонами при сбое (фейловер);
- на начальном этапе не использовать шардирование БД, но запланировать его возможность в будущем.
